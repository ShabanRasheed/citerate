01 · Thesis

One sentence, then the consequences

CiteRate tells a site owner how often AI answer engines cite them, and why they were not cited when they weren't.

Everything else in the product is downstream of that sentence. Rank trackers answer a question search engines stopped asking; brand-mention tools count noise. The measurable unit here is the citation — a link an engine actually handed a user — and the deliverable is a named cause a marketer can act on this week.

11/60 — 18%
Every rate carries its run count. A bare percentage is a bug, not a simplification.
62 ±6
An estimate without a confidence band never ships. Movement inside the band is labelled within noise.
SURFACEPROXY
Each engine discloses how it was measured, everywhere its number appears.
"Other / unexplained" is a permanent, striped segment. A tool that always has a diagnosis is a horoscope.
02 · The loop

Five stages, and the screen that owns each

The product is a closed loop, not a dashboard. Stage 5 feeds stage 1: a verified fix changes the next scan's rate, and that delta is the proof an agency bills against. If any stage is missing the loop leaks — this is why the Fix Queue is not optional above Starter.

STAGE 1
Measure

Run the tracked query set against every enabled engine, N times, and record each run as cited / mentioned / absent.

/overview · /queries
STAGE 2
Attribute

For each uncited query, weigh four pieces of evidence and either name one of three causes or refuse to.

scoring.ts · attribute()
STAGE 3
Prioritise

Rank the fixable set by recoverable citations × effort. Technical decay first — engines that can't read a page explain nothing else.

/fixes
STAGE 4
Fix

The user edits their own page. We hand over the specific change, the URL, and the queries it should recover. Then they mark it shipped.

/fixes · api/fixes/[id]
STAGE 5
Prove

The next scan re-measures only those queries. If the rate moves outside the band, the fix is stamped verified and frozen into a report.

/reports/[id] → back to 1
CLOSING EDGE Stage 5 → Stage 1. The only number the product is judged on is the delta between two scans that straddle a shipped fix.
03 · Measurement pipeline

What happens between "scan" and a number on screen

01
Query set resolved
Seed queries from the domain's topic clusters, plus anything the user added or imported from Search Console. Free tier caps at 25.
seed-queries.ts
02
Runs executed
Each query is put to each enabled engine multiple times. Engines are labelled SURFACE (we read the real answer panel) or PROXY (we infer from an API that approximates it). The label never gets dropped downstream.
api/scan/[id]
03
Run classified
Four booleans per run: cited (our host is linked), mentioned (named, not linked), aioPresent (an AI answer existed at all), and which competitor hosts were cited instead.
RunResult
04
Rate + band computed
Citation rate = cited runs ÷ total runs, over runs and never over one lucky answer. A Wilson score interval gives the band drawn on every trend chart; two overlapping bands mean the delta is noise and the UI says so.
confidenceBand()
05
Cause attributed
Technical decay is tested first, then ranking decline, then AIO displacement. Anything scoring under the 0.6 confidence floor is returned as unexplained rather than guessed.
attribute()
06
Fix drafted
A named cause maps to a fix template: the URL to change, the change itself, and the queries expected to recover. Unexplained never produces a fix.
/fixes
07
Snapshot frozen
The month's readout is written to report_snapshots with the method version that produced it. Reports are immutable: a later method change flags a discontinuity instead of silently rewriting history.
0002_app.sql
CAUSE 1 · AIO DISPLACEMENT

An AI answer appeared, our rank held in the top 5, the page is healthy — and somebody else got cited. The page is fine; the answer surface changed.

CAUSE 2 · RANKING DECLINE

Organic position slipped past 8 or moved in the trailing window. Ordinary SEO work, correctly diagnosed as ordinary rather than blamed on AI.

CAUSE 3 · TECHNICAL DECAY

Not fetchable, not indexable, or unstructured. Checked first and weighted highest: if engines cannot read the page, no other explanation means anything.

04 · Object model in plain language

Nine nouns the whole product is built from

If a screen introduces a tenth noun, it is a design bug. Every flow in 9c moves a user between these objects.

workspace

The billing and permission boundary. One company, or one client of an agency. Owns domains, seats, plan, brand settings.

membership

A user's role inside one workspace: admin, editor, viewer, or client. Notification prefs hang off the membership, not the user — an agency lead does not want every client's Monday digest.

domain

A verified hostname. Verification is what makes a second workspace's claim on the same host a join request instead of a duplicate.

query

A prompt a real buyer would type. Grouped into topic clusters. The plan's trackedQueries limit counts these.

run

One query, put to one engine, once. The atomic unit of evidence and the denominator of every rate on screen.

verdict

The rollup of a query's runs: rate, band, cause, confidence, and which competitors were cited instead. What the evidence drawer shows.

fix

A specific change to a specific URL, with the queries it should recover. Moves through open → shipped → verified (or → no change).

snapshot

A frozen readout for a period, stamped with its method version. Immutable by design — the whole trust story rests on it.

saved view

A named filter set on Queries. Cheap to build and the thing that turns a 500-row table into somebody's Monday routine.

05 · Cadence

What the product does while nobody is looking

NIGHTLY
Scheduled scan

Daily on Growth and above, weekly on Starter, once ever on Free. Writes runs, recomputes verdicts, re-tests any query attached to a shipped fix.

ON DELTA
Alerts

Rate-drop alerts fire only when the move falls outside the confidence band and past the user's threshold (default 5 points). Noise never emails anyone.

MONDAY 08:00 LOCAL
Weekly digest

Per membership. Score, delta with band, top three fixes, one competitor line. Opt-out is per workspace.

1ST OF MONTH
Snapshot + PDF

Freezes last month's readout, renders the PDF into R2, and notifies whoever owns the client relationship. White-label on Scale and Agency.

DEPTH RULE

Nothing in the app is more than two clicks from the sidebar. The evidence drawer is a drawer, not a route, so a query never becomes a third level.

SCOPE RULE

Every app route reads inside one workspace + one domain. Switching either re-scopes the whole shell, never a partial page.

GATE RULE

Locked features render blurred-but-real, never hidden. The user sees the shape of what they'd get; upsell sits on top of their own data.

SEAM RULE

One token type crosses the boundary. Marketing mints, the app redeems, and the redemption is also the account creation.
