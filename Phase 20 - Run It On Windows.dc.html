Both halves of Citerate, running on Windows in about fifteen minutes

You end up with three terminals open: the marketing site on port 4321, the scanner ticking once a minute, and the dashboard on port 4322. All three read one local database file. Scans run the real pipeline with fake engine answers, which costs nothing — Phase 22 turns the real engines on.

Use PowerShell, not Command Prompt. Run each block from the folder the step names.

One thing matters more than any command here: the two folders must sit side by side, named citerate and citerate-app. The dashboard finds the shared database at ../citerate/.wrangler/state. Rename or nest either folder and the dashboard reads an empty database while the site reads a full one.

1 · Install Node and pnpm

Node 20.11 or newer, pnpm 9 or newer. Node 22 LTS is a safe pick. Install Node from nodejs.org, then let Node install pnpm for you.

corepack enable
corepack prepare pnpm@9 --activate
node -v
pnpm -v
expect
Two version numbers, the first v20.11.0 or higher, the second 9.x or higher. If corepack is not recognised, your Node is too old — reinstall it.

2 · Get the code onto disk

Download the project from this workspace and unzip it somewhere short, like C:\citerate. Deep paths under Documents plus long dependency names can hit the Windows path limit. Avoid OneDrive folders — its file syncing fights the database file.

expect
A folder holding citerate\ and citerate-app\ next to each other.

3 · Check the folder shape

cd C:\citerate
dir
expect
Both folder names listed. If you see one folder containing the other, move them so they are siblings before going on.

4 · Install the site

cd C:\citerate\citerate
pnpm install
expect
A package count and Done. It will ask to build esbuild, sharp and workerd — say yes; they are already allowed in package.json. Two to three minutes on a first run.

5 · Make the .env file

Copy the example. The defaults are deliberately safe: Cloudflare's always-passes Turnstile test key, mock engines on, no billing.

Copy-Item .env.example .env
notepad .env

Change one line only — SESSION_SECRET. Any 32 or more random characters will do locally. Leave USE_ENGINE_MOCKS=true.

expect
A .env file sitting next to package.json. It is gitignored, so it never leaves your machine.

6 · Create the database and fill it

The first command creates the local database file and builds every table. The second drops in a demo workspace, a domain, a finished scan and its findings, so the dashboard has something to show before you run anything.

pnpm db:migrate:local
pnpm db:seed:local
expect
Wrangler reports the migration applied, then a row count from the seed. A new .wrangler\state folder appears — that folder is your local database. Delete it any time you want a clean slate, then re-run these two commands.

7 · Start the site — terminal 1

pnpm dev
expect
localhost:4321 in the output. Open it. You should get the home page with the scan form. Leave this terminal running.

8 · Start the scanner — terminal 2

Submitting the scan form writes a job row. This worker is what picks the job up. Without it, scans queue and never finish.

cd C:\citerate\citerate
pnpm scanner:dev
expect
A worker URL and a note about the cron trigger. It ticks every minute, so a scan can sit for up to sixty seconds before it moves. That is normal, not a hang.

9 · Install and start the dashboard — terminal 3

cd C:\citerate\citerate-app
pnpm install
Copy-Item .env.example .env
pnpm db:migrate:local
pnpm db:seed:local
pnpm verify:local
pnpm dev

The migrate and seed here point at the same database file as the site — that is what the --persist-to ../citerate/.wrangler/state flag inside those scripts does. verify:local is a doctor script that checks the wiring before you open a browser.

expect
The doctor passes, then localhost:4322. Sign in with the seeded account the doctor prints. If the overview is empty, the shared-database path is wrong — go back to step 3.

That is the full experience. The only unreal part is what the engines said — every number is computed from those mock answers by the same code that will compute it from real ones.

When it breaks

symptomcause and fix
Dashboard overview is empty, site works fineThe two folders are not siblings, or you renamed one. The dashboard made its own empty database. Fix the folders, delete citerate-app\.wrangler, re-run its migrate and seed.
Scan sits at "queued" foreverTerminal 2 is not running, or it crashed. The cron ticks once a minute; give it that long before worrying.
Port already in useSomething else holds 4321 or 4322. Close it, or run pnpm dev -- --port 4331 and update PUBLIC_SITE_URL to match.
Install fails on a long pathMove the project to C:\citerate and out of OneDrive. Then git config --system core.longpaths true if you cloned.
Something elseRun pnpm preflight:local in either repo. It names what is missing rather than guessing.
