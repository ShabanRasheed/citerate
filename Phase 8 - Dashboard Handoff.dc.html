Citerate · Phase 8 Dashboard handoff · runs locally

The other half: the app people log into

Around 120 files in /citerate-app — a separate Pages project on the same D1 database, with the opposite JS balance the Phase 6a decision called for: Bootstrap's JS, Alpine, and ECharts here; forty-line modules on marketing. Every screen from phases 3b, 4, and 5 is built except 2FA enrolment: passwordless auth, three-step onboarding, the readout, the dense query table, the Fix Queue, immutable reports, team and billing. Seeded dev data ships with two scans, so the delta, the confidence band, the method flag, and a verified fix are all visible on first run.

02

Auth, as built

One token, two doors
The link and the code are the same row
Stored as hash(secret:code); the secret half lives in KV for the token's 15-minute life so the typed-code path can verify. Clicking the link after typing the code gives "already used", not two sessions.
Sessions
The database can't replay your cookie
D1 keeps only SHA-256 of the cookie value. "Trust this device" is off by default: one day, not thirty. Devices are listed with labels, and "sign out everywhere else" is on the account pane, not buried.
No dead ends
A taken domain becomes a request
Someone else verified northline.co? We file a join request that expires in 7 days and tell them it was sent. Two workspaces measuring one domain would double-count the same runs.
Enumeration is closed on purpose: the response to a sign-in request is identical for known emails, unknown emails, and rate-limited requests. Same for the email-change form — an address already in use gets the same "confirmation sent" as a free one.
03

Five roles, and why client matters

RoleWhat it can doCosts a seat
owner Everything, including billing, branding, and deleting the workspace yes
admin Everything except billing and deletion — invites, tracking, branding yes
editor Queries, fixes, rescans. No invites, no money yes
viewer Read and export. Cannot change what is measured yes
client Read only, no exports, no settings — the agency's client seat free · unlimited
Capabilities live in lib/rbac.ts and are checked in the route, not just hidden in the UI — every write endpoint returns 403 on its own. That is what makes "share the dashboard with your client" safe to advertise: sharing never costs a seat, and a client seat cannot spend money or change tracking.
04

The method rules, enforced in code

Charts read one table
lib/data.ts reads daily_rollups for every chart — never a live aggregate over observations. The Wilson band ships from the rollup row, and the trend chart draws it as a ribbon so movement inside it looks like what it is.
"Within noise" is a state
The score unit prints within noise instead of an arrow when the two bands overlap. There is no code path that shows a delta we cannot defend.
Verified is measured
The state select disables verified and api/fixes/[id] rejects it with 422 verified_is_measured_not_set. Marking shipped queues nothing but the next scan; the card says so.
Reports don't move
A snapshot stores the payload and the method version. A rule change flags affected history instead of rewriting an issued PDF — and white label cannot remove the methodology note.

06

Deliberately unfinished — and labelled in code

Paddle price ids api/billing/checkout.ts has the map commented out and returns 501 billing_not_configured until it's filled. The webhook — the half that must be right before money moves — is already HMAC-verified in the marketing repo.
Search Console callback The consent hop is written; the callback and token storage are not. Ranking-decline findings publish without it at lower confidence, and onboarding says that out loud rather than hiding it.
Seeded 25 queries Same placeholder as the site's api/scan.ts: lib/seed-queries.ts is a category template, written to the database as source: 'category' so nothing claims to be crawl-derived.
PDF renderer · 2FA · fonts artifact_key stays null until a renderer writes to R2 — /reports/[id] is already the print source and prints correctly. totp_secret exists and is read; enrolment screens aren't built. Copy the four woff2 files into public/fonts/.
One rule to keep the halves honest
Six lib files are byte-identical copies, on purpose
env.ts · db.ts · plans.ts · scoring.ts · email.ts · domain.ts are duplicated because two Pages projects share no package. Edit them in citerate/ first and copy across — if they drift, the site and the app will disagree about what counts as a citation, which is the one disagreement this product cannot survive.
