Focus order
Skip-link → sidebar nav → topbar (workspace, search, account) → page h1 → primary action → filters → table. Tab never enters a chart's data points; charts expose one tab stop plus arrow-key stepping with a live-region readout.
Modals trap focus and return it to the trigger. Drawers focus their heading and return to the row. Toasts are aria-live="polite" and never steal focus.
Focus is only ever shown with :focus-visible, never suppressed, and always the same 4px #3E5C8A ring outside a 2px white gap (#7FA0D4 on the ink sidebar).
Feedback taxonomy
Inline — anything about one field. Replaces the hint, red text, no icon soup.
Toast — transient success that may need undo. 5s, one action, one at a time, bottom-left, above the sidebar.
Banner — screen-level truth that outlives a moment: quota reached, scan failed, domain unverified, card expiring. Persistent, dismissible only if it's informational.
Modal — destructive or billing confirmation only. Typed confirmation for workspace delete and domain change.
Never a toast for an error the user has to act on.

06

Standing rules

Always
Animate transform and opacity. The one exception is the expand's grid-template-rows.
Reserve space before content arrives — skeletons match the real row height, numbers use tabular-nums, busy buttons keep their width.
Put filters, sort, date range, open row and selected cause in the URL. A pasted link reproduces the screen.
Give every destructive or paid action a confirm, and every reversible one an undo.
Honour prefers-reduced-motion by cutting duration to ~0 while keeping the end state — no feature disappears.
Never
Replay the score arrival on refilter, tab change, or route return. Data that's already known appears instantly.
Hover-only meaning, hover-only actions, or a tooltip carrying information that isn't elsewhere.
Spinners over content the user is already reading, or a skeleton on a refetch of data you have.
Two toasts at once, a toast for an actionable error, or a banner that auto-dismisses.
Springs, bounces, parallax, scroll-jacking, celebratory animation on a number that means lost traffic.
Open flags: virtualised rows plus j/k highlight need one owner in code, or the highlight will drift out of the rendered window on fast scroll. The command palette (⌘K) has no screen yet — it's specified here but not designed. Chart brushing on touch conflicts with page scroll; mobile Trends falls back to a range dropdown.
