01 · Foundation

Why this direction

A verdict is a sentence

So the display face is a serif. It carries plain-language diagnosis with the authority of a written opinion — and it structurally prevents the page from opening with a grid of widgets.

Every number is mono

Kept from the prototype and made absolute: rates, counts, scores, deltas, timestamps, tokens and code are JetBrains Mono. Tabular figures mean columns of rates align without a table layout.

Chrome costs nothing

UI text uses the system stack, so both webfonts are spent where brand lives. Marketing LCP is a serif headline over flat paper — no hero image, no gradient, no framework.

The four invariants this system renders
11/60 — 18%
Rates carry their run count. A bare percentage is a bug.

An estimate without a band is not shipped.

03 · Color

07 · Motion

Motion explains sequence, never decorates

One rule governs the dashboard load: the verdict settles first. Nothing else moves until the sentence is readable — the user's question is "what's wrong", and the answer arrives before the evidence.

Dashboard load420mssettleVerdict fades up 6px (0ms) → score count-up (120ms) → cause bar segments draw left-to-right, 40ms stagger (200ms) → cards fade in (320ms). Total under 1s.
Score count-up700msout0 → 62 with the arc sweeping in sync; band arc appears at the end so the estimate never looks more precise than it is. Once per session only.
Cause segment select160msoutRing draws on the segment; unrelated table rows drop to 40% opacity, then the filtered set re-flows. No layout jump — heights are reserved.
Row expand240msin-outgrid-template-rows 0fr→1fr, chevron rotates 180°, content fades at 60% of the way. Only one row open.

Hover / press90msoutBackground and border only. Press translates 1px down. Nothing scales, nothing lifts.
reduced-motion0ms—All durations collapse to 0; the count-up prints the final number; bars appear drawn. Every state change still lands — no feature is motion-dependent.

Flags — decisions I need from you
Amber is not AA as text. #D98324 is 2.6:1 on white, so "Partial" pills use #9A6210 text on a wash. The bar fill stays #D98324 (3:1 for graphics is met). No invariant broken — flagging because the prototype used amber for label text.
Serif at 380px. Display drops to 30px on mobile; a 3-line verdict is normal there. If you'd rather cap the verdict at two lines, we shorten the sentence pattern, not the type.
Score arc vs. ruled bar. The arc is the on-screen unit; the PDF flattens it to a ruled horizontal bar because arcs print poorly at small sizes and white-label accents distort them. Two renderings of one number — confirm that's acceptable.
Sidebar under 900px. Off-canvas drawer, not a bottom tab bar — the app has 9 destinations and tabs would hide the fix queue badge. Say the word if you want tabs for the top 4.
