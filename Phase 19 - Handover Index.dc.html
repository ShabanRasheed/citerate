Eighteen phases, in the order they happened

Phases 1 to 6 decided what CiteRate looks like and says. Phases 7 and 8 turned that into the two repos. Phase 9 wrote the UX documentation around it. Phases 10 to 13 closed the loose ends. Phase 14 is the clickable prototype. Phases 15 to 18 are live checks that read the repos and re-run every time you open them, so they cannot go stale.

Nothing in the design work is outstanding. What is left is four decisions and one deploy, listed at the bottom.

What is left

four items · none of them design
01 · yours to decide
Git-based deployment

Deliberately deferred. Nothing is wired for the Pages Git integration and nothing will be until you say so. Deploys go through pnpm deploy today.

02 · yours to run
The first real deploy

Phase 17 lists the secrets and vars to set; Phase 11 has the ordered steps. Both repos deploy separately against the one shared database.

03 · scoping call
The 7 prototype-only views

Shared scan view, shared report link, a standalone verify-fix screen, a schedule tab. Each is either a real page later or a state on an existing page. Nothing breaks either way.

04 · optional
Parity checks not yet written

The live checks cover routes, CSS, breakpoints and deploy config. Copy, database schema, and the auth flow have designs but no automated board watching them. Worth adding only if you want the same guarantee there.
